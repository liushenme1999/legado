# Markdown 阅读界面帮助

## 视图说明
本视图专用于 `.md` / `.markdown` 文件,使用 Markwon 渲染:
* 标题、段落、加粗/斜体、行内代码
* 有序/无序列表、嵌套列表
* 引用、围栏代码块、水平线
* GFM 表格
* 图片(自动加载与 Markdown 同目录的本地图片,以及网络图片)

## 顶部标题栏
* **左侧返回箭头**:返回上一页
* **标题**:当前书籍名
* **副标题**:`当前章 / 总章数`
* **右上角菜单(三个点)**
  * **书签**:在当前阅读位置创建书签,可在"目录"界面的"书签"页查看
  * **刷新目录**:重新解析 `.md` 文件并重建目录
  * **帮助**:显示本帮助内容

## 阅读内容区
* 可上下滚动浏览
* 长按选中文字可复制
* 列表/表格/代码块/图片由 Markwon 渲染,无需翻页

## 底部功能栏
* **上一章 / 下一章**:跳到前后一章,边界时弹出提示
* **章节进度条**:拖动到目标章节释放即可跳转,粒度为"章"
* **目录**:打开目录与书签界面(沿用应用通用的 `TocActivity`),可搜索、可切换章节、可管理书签
* **夜间**:切换日/夜间主题
* **刷新**:重新解析 `.md` 文件并重建目录(等同顶部菜单的"刷新目录")

## 手势操作
* **垂直滚动**:浏览内容时,顶部标题栏与底部功能栏会自动隐藏,沉浸阅读
* **点击屏幕中间区域**:重新显示顶部标题栏与底部功能栏
* **向左长滑动**:切换到下一章
* **向右长滑动**:切换到上一章

## 进度保存
* 退出阅读视图时会自动保存当前章节序号与滚动位置
* 下次再次打开该书自动回到上次阅读位置

## 其它
* 切换日/夜间模式或修改 `.md` 源文件后会重建解析缓存
* 网络图片(`http://` / `https://`)与本地相对路径图片(同目录或子目录下)都会被识别和显示
